# Roadmap

- Build publishing drafts, approvals, scheduling and post history when the publishing workflow is requested.
- Add read-oriented engagement and topic reports, with reviewed suggestions for replies.
- Add explainable goal-based discovery for new accounts and a separate cost preview before expanded retrieval.
- Evaluate a remote MCP transport with per-account grants and secure private connectivity for eligible ChatGPT plans.
- Validate DCC catalog deployment and runtime on a physical Ubuntu Server Raspberry Pi after the Windows release is tested.

The current edition supports confirmed single-profile follow and unfollow. Scheduled jobs scan and classify. The publisher, autonomous engagement and trend intelligence are future extension points.
